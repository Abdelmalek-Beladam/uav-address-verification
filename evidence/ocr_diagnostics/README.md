# OCR diagnostic evidence

These are historical diagnostic outputs, not a trained OCR checkpoint or an independent accuracy benchmark. The 180-row PaddleOCR CSV represents 30 items under six processing variants, not 180 independent images. The EasyOCR digits CSV has 30 reviewed items. The 24-row pipeline summary includes agreement with reference addresses, which must not be called OCR ground truth or end-to-end verification accuracy. EasyOCR was investigated but not selected for the final pipeline.
