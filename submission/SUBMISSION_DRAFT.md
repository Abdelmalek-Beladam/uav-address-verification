## Project name
AI-Powered UAV for Automated Addressing Detection & Verification

## Summary — under 20 words
Software for UAV-assisted address inspection, combining number recognition, geographic checks and an evidence-review workspace.

## Description — under 150 words
We are developing a UAV-assisted workflow for checking visible house numbers against official address records. Our implemented prototype processes recorded Paris street imagery offline, detects number plates, reads their numbers, groups observations across views and compares estimated locations with the municipal address register.

An interactive browser workspace lets reviewers inspect source images, compare candidate addresses, record local notes and export evidence. It separates reading a number from verifying its location and leaves ambiguous cases for review.

The demonstration uses previously processed recordings; it does not perform fresh browser inference. UAV image acquisition, flight control and onboard processing are planned rather than implemented. Current evidence demonstrates the software workflow, not independent end-to-end accuracy or a deployed aerial service.
