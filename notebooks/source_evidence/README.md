# Historical source notebooks

These notebooks document the original experiments and integration work. They are not a clean sequential install/run interface. Do not Run All: they include training, diagnostic comparisons, package installation and earlier pipeline variants. Cell sources are preserved; outputs and runtime metadata were removed for repository presentation. Original uploaded notebooks remain unchanged in the source archives.

Canonical current runner: tools/run_street.py. Saved-results reproduction: tools/reproduce_saved_release.py. The final app uses the selected Amira YOLO26n checkpoint and pretrained PaddleOCR recognition, not Abdelmalek's earlier YOLO11n or EasyOCR comparison pipeline.
