# Data credits and provenance

## Reference database

Adresses de Paris, Ville de Paris / Direction de l'Urbanisme. ODbL: https://opendata.paris.fr/explore/dataset/adresse_paris/ and https://opendatacommons.org/licenses/odbl/ . Preserve attribution and applicable database obligations for derived exports.

The packaged CSV contains 153,467 rows. The 2013 date is the dataset's initial publication, not proof that every address is from 2013. The exact packaged retrieval date and identity with the current online revision remain unestablished. This is a saved snapshot, not a live/latest feed.
